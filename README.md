# 👨‍💻 Raj Jakhaniya – Developer Portfolio

A modern, responsive, and interactive personal developer portfolio built using **HTML, CSS, and JavaScript**. This portfolio showcases my academic journey, technical skills, internship experience, education, and web development projects in a clean dark-themed interface.

## 🌟 Project Overview

This portfolio website was designed and developed as a single-page web application to present my profile as an **MCA student and aspiring web developer**. The website features a sleek dark navy theme with gradient accents, responsive CSS Grid/Flexbox layouts, inline SVG icon sprites, and lightweight JavaScript interactivity.

The project aims to provide recruiters, fellow developers, and visitors with a clear and accessible overview of my practical development work, technical background, and contact channels.

## ✨ Features

- **Modern Dark UI Design:** Sleek dark navy interface (`#080d18`) with radial background glows and subtle gradient highlights.
- **Responsive Layout:** Optimized for desktop, tablet, and mobile screens across multiple breakpoints (`950px`, `720px`, and `450px`).
- **Sticky Glassmorphic Header:** Translucent navigation bar with `backdrop-filter` blur and smooth section scrolling.
- **Accessible Mobile Navigation:** Interactive hamburger menu with ARIA attributes, automatic closing on link selection, and desktop resize reset.
- **Personal Profile Card:** Custom hero profile panel displaying education, development focus, and location details.
- **Quick Facts Bar:** At-a-glance highlights of current academic status, internship role, and project experience.
- **Categorized Technical Skills:** Six structured skill cards covering Frontend, Programming, Database, Development Concepts, Tools, and Computer Science fundamentals.
- **Project Showcase:** Detailed cards for featured projects with key highlights, tech tags, live links, and GitHub links.
- **Internship & Education Timeline:** Dedicated sections detailing work experience at IT Hub Software Solutions and academic qualifications from SSC to MCA.
- **Accessibility & Motion Support:** Keyboard focus indicators and `@media (prefers-reduced-motion: reduce)` support.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/raj-jakhaniya/portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd portfolio
```

### 3. Run the Website

Open `index.html` in your preferred web browser.

**Recommended:** Use Visual Studio Code with the Live Server extension for a better development experience.

## ⚙️ Functional Implementation

JavaScript is used to implement lightweight, dependency-free interactivity, including:

- Mobile hamburger navigation menu toggle with `aria-expanded` and `aria-label` updates.
- Automatic closing of the mobile navigation drawer when a section link is clicked.
- Automatic reset of mobile menu states when resizing the browser window above `720px`.
- Dynamic rendering of the current year in the footer copyright notice.

## ⚠️ Project Limitations

- This is a static frontend-only portfolio website.
- No backend server or database integration is included.
- Contact actions rely on direct `mailto:` email links and external social profile links rather than a server-processed contact form.

## 🎯 Project Objectives

- Build a clean, fast, and responsive personal portfolio without external CSS or JS frameworks.
- Showcase practical web development projects, internship experience, and academic milestones.
- Apply semantic HTML5, modern CSS layout techniques, and accessible UI practices.
- Provide recruiters and collaborators with an easy way to review my work and get in touch.
